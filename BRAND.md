# Why the Code — Brand Kit

## Brand idea

Why the Code helps developers trace code back to the decisions, people, and events that shaped it. The identity uses a connected path that ends at a highlighted answer: follow the graph, find the reason.

## Name and voice

- **Product name:** Why the Code
- **Compact UI wordmark:** why.
- **Tagline:** Follow the why.
- **Voice:** direct, calm, evidence-led, and honest about uncertainty.
- Avoid using **WTC** in public-facing copy. It is hard to interpret without context and can read as “What The Code.”

## Visual system

- **Graphite:** `#10120F` — app background
- **Deep panel:** `#151813` — logo surface and cards
- **Lime:** `#D2F06C` — selected node, action, and key answer
- **Sage:** `#A7B1A3` — supporting nodes and secondary information
- **Fog:** `#E7E9E2` — primary text
- **Muted:** `#81877B` — supporting text
- Use Manrope or a clean system sans for display text; use Cascadia Code, SFMono-Regular, or Consolas for technical labels.

## Logo assets

- `public/brand-mark.svg` — scalable app and social avatar mark.
- `public/wordmark.svg` — full horizontal lockup.
- `public/favicon.svg` and `public/favicon.ico` — browser icon assets.

Keep the mark on a dark surface or use the SVG with its built-in dark tile. Do not recolor the lime path or stretch the lockup.
